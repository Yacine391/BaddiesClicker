# Baddie Clicker — Lot P0 Codeur B : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer le client P0 (HUD Fusion style V3, fenêtres Book/Style/Crew/Réglages, suiveurs, podium, auras, placeholders et lobby) branché sur le vrai serveur du Codeur A via `StateController`.

**Architecture:** Logique d'affichage en modules purs (`src/client/Logic`) testés avec Lune ; état client en valeurs Fusion alimentées uniquement par les snapshots `State` ; composants Fusion réutilisables ; placeholders et lobby construits dans Studio via le MCP puis exportés en `.rbxm` dans `assets/` et mappés par Rojo.

**Tech Stack:** Luau `--!strict`, Rojo 7.7.1, Fusion 0.3 (tag `v0.3-beta`, copié), Lune 0.10.4, Selene 0.32, StyLua 2.6, MCP Roblox Studio.

**Spec:** `docs/superpowers/specs/2026-10-14-p0-codeur-b-design.md` (révision 2), avec `docs/CONTRACT.md` (v1) et `docs/proposals/2026-10-14-contract-v2-collection.md` (v2).

## Global Constraints

- Branche `b/p0-client` ; jamais de push sur `main`. Push et ouverture de PR seulement après accord explicite de l'utilisateur.
- Le Codeur B ne modifie que `src/client/` (sauf `Controllers/StateController`), `assets/`, `licenses/`, `tests/client/`, `docs/`. Exceptions déjà convenues, à signaler dans la PR : `Flags.DEV_HUD = false`, `default.project.json` (mapping `assets/`), `.styluaignore` et `selene.toml` (exclure `src/client/Packages`).
- Réseau client : uniquement `StateController.onState`, `.onResult`, `.send(action, payload?)`. Jamais `FireServer` direct, jamais de montant envoyé.
- Chiffres affichés : `Shared/Format.number`. Constantes : `Shared/Balance` (ex. `Balance.training.holdActionsPerSecond` = 3). Noms, raretés, palettes, looks : `Shared/Catalog`.
- Modules `Logic/*` **[pur]** : aucune API Roblox, aucun `require` ; `Catalog`, `Format.number` passés en paramètres.
- Polices `Font.fromName("LuckiestGuy")` et `Font.fromName("FredokaOne")` ; cibles tactiles ≥ 48 px ; `UIScale` base 1280 × 720.
- Couleurs `Theme.Colors` : Nuit `#242036`, Violet `#7642A3`, Cyan `#13A6B5`, Or `#D7A746`, Crème `#F4EEE7`, Contour `#1B1530`, Action `#33B84A`, Fermer `#E0233F`.
- Nommage visuel : `B01_Maya/Look01|Look02|Look03`, `C02_Malik/Base`, `TEST/TEST_B99` ; attachments `AuraAttachment`, `NameTagAttachment` ; `AnimationController` + `Animator`, aucun `Humanoid`.
- Avant chaque commit : `lune run tests/run` et `lune run tests/client/run` à 0 échec, `selene src` à 0 erreur, `stylua src tests`.
- Messages de commit conventionnels terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Snapshot incomplet ou inattendu** (v1 sans `collection`, `crew` vide, slot actif vide → `active.baddieId == nil`, ID absent du `Catalog`, `power` NaN ou 1e15) : le HUD s'affiche sans erreur avec des valeurs neutres. → tests `HudModel` (Tâche 2).
2. **Clic à travers une fenêtre ouverte** : aucune intention `Train` tant qu'une fenêtre est ouverte (rubrique 21). → vérification Play (Tâche 6).
3. **Clics en rafale / maintien** : le maintien n'envoie pas plus de 3 actions/s ; le chiffre affiché ne bouge qu'avec les snapshots, jamais par prédiction. → vérification Play (Tâche 6).
4. **Joueur qui part, ou attributs `BC_*` pas encore prêts** (`BC_Ready` faux) : aucun suiveur construit trop tôt, aucun modèle orphelin après départ. → vérification à 2 joueurs (Tâche 10).
5. **Identité de test dans le compteur public** : `test_b99` n'est jamais comptée dans « n/8 ». → test `HudModel.bookCount` (Tâche 2).

### Task 2: HudModel [pur]

**Files:**
- Create: `src/client/Logic/HudModel.luau`
- Test: `tests/client/run.luau` (groupe « HudModel »)

**Interfaces:**
- Consumes: forme du snapshot (`docs/CONTRACT.md`, champ `collection` du v2 facultatif) ; `Catalog` ; `format: (number) -> string` (= `Format.number`).
- Produces: `HudModel.build(snapshot: {[string]: any}?, Catalog: any, format: (number) -> string): HudView` avec
  ```luau
  type HudView = {
    ready: boolean,
    powerText: string,
    productionText: string?,      -- nil si aucun compagnon
    ticketText: string,
    principal: { name: string, rarityLabel: string, rarityColor: string, multiplierText: string, slotText: string }?,
    tutorial: { visible: boolean, text: string, ratio: number },
    button: { label: string, colorKey: "Action" | "Fermer" },
    bookCount: { discovered: number, total: number },
  }
  ```
  Règles : `ready = snapshot ~= nil` ; `powerText = format(power)`, ou `"—"` sans snapshot ; `productionText` = `"+" .. format(passivePerSecond) .. "/s " .. Catalog.crew[id].name` avec un compagnon, `"+" .. format(passivePerSecond) .. "/s Crew"` avec plusieurs ; `ticketText = format(tickets.baddie)` ; `principal = nil` si `active.baddieId` est nil ou inconnu du `Catalog` ; `multiplierText = "×" .. format(multiplier)` ; `slotText = "Slot " .. tonumber(string.sub(slotId, 2))` ; tutoriel visible si `crewUnlocked == false`, `text = "Malik arrive : " .. progress .. "/" .. needed` ; bouton `ENTRAÎNER`/`Action` si `mode == "rest"`, `ATTAQUER`/`Fermer` si `"combat"` ; `bookCount.discovered` = nombre d'IDs de `collection.discovered` présents dans `Catalog.baddies` (ou 1 si `collection` absent et principale connue), `total = #Catalog.baddieOrder`.
